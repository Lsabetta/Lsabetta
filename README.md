# Luigi Sabetta

AI/ML researcher with a Ph.D. in Physics, with experience across CERN, Leonardo Labs, and applied machine learning research.

My research interests include continual learning, machine unlearning, large language models, computer vision, efficient deep learning, and data-driven modeling.

## Selected work

- **[MIND](https://github.com/Lsabetta/MIND)** — Continual learning method based on multi-task incremental network distillation. Published at AAAI.
- **[Clinical Evidence Agent](https://github.com/Lsabetta/clinical-evidence-agent)** — Research-oriented AI agent for clinical evidence retrieval and analysis. Work in progress.
- **[Vivado CNN](https://github.com/Lsabetta/Vivado_CNN)** — Tools and implementations for low-latency CNN inference on FPGA hardware.

## Research background

Previously:
- AI Research Fellow at **Leonardo Labs**, working on continual learning and machine unlearning for computer vision and LLMs.
- Ph.D. Researcher at **CERN**, working on large-scale data analysis, machine learning, model compression, and ultra-low-latency neural network inference.
